# Scout 6: AWS, Google Cloud and Azure for a small multi-tenant PWA backend

Research date: 2026-10-24. All figures were fetched on that date. Raw pages are in (raw pages not kept). Extracted text and the parsing scripts are in (raw pages not kept).

## Method and labels

- Regions: AWS ap-south-1 (Mumbai), Azure Central India, GCP asia-south1 (Mumbai) where the vendor page allowed it.
- Prices are USD. Azure Retail Prices API calls used the default currency (USD).
- "(d)" means derived: a quoted unit price multiplied by 730 hours per month (AWS and Azure convention), or by 2,628,000 seconds per month for GCP per-second rates. The arithmetic is shown. No price is taken from memory.
- "UNKNOWN" means not verified in this run.
- The AWS EC2 bulk file for ap-south-1 is 314,675,647 bytes, over the 300 MB cap, so it was not parsed. EC2 and NAT gateway Mumbai prices are therefore UNKNOWN.
- The Cloud SQL and Cloud Run pricing pages are region-selector pages. Only some Mumbai values appear in the page data.
- The GCP Cloud Run button docs page returned 404, and the GitHub README returned 403. The deploy-button claim for GCP rests on a search-result summary (secondary).

## Decision rule applied

Drop an option only if its S2 monthly floor is above USD 25 and it needs heavy owner maintenance. Result: no option meets both conditions on verified data, so no option is DROP.

- Self-managed VMs (Lightsail, Azure VM) are cheap (about $7 to $12) but carry high maintenance, so they stay KEEP.
- Managed options are above $25 in a few cases (Azure App Service plus Postgres about $31 (d); AWS Fargate plus RDS about $27 (d)), but their maintenance is low, so they stay KEEP.
- EC2 and GCE have unverified Mumbai prices, so they cannot be dropped on this evidence.

## 5. Gotchas (hidden charges and traps)

- AWS public IPv4: $0.005 per in-use or idle address per hour in ap-south-1 (AmazonVPC bulk). That is 3.65 (d) per address per month. Lightsail bundles include IPv4, so they avoid this.
- AWS NAT gateway: charged per NAT-gateway-hour plus per GB processed (AWS VPC pricing page, quoted above). The Mumbai hourly rate is UNKNOWN because it sits in the unparsed EC2 bulk file.
- RDS Multi-AZ doubles the instance price ($0.042/h vs $0.021/h, Mumbai).
- RDS backup storage beyond the free allocation: $0.095/GB-mo (Mumbai). The free allocation amount is UNKNOWN in this run.
- Aurora PostgreSQL Serverless v2 extended-support charges apply to older majors: $0.097/ACU-h in years 1 and 2, and $0.194/ACU-h in year 3 for PG 13 to 15 (AmazonRDS bulk, Mumbai). PG 18 avoids this.
- Aurora storage $0.11/GB-mo and I/O $0.22 per million requests (Mumbai).
- App Runner bills provisioned memory while idle: $0.007448/GB-h (Mumbai). Active vCPU is $0.068096/vCPU-h.
- Fargate ARM is cheaper than x86 in Mumbai: $0.02383 vs $0.04256 per vCPU-h.
- CloudWatch Logs (Mumbai): standard ingestion $0.67/GB; storage $0.03/GB-mo; indefinite retention by default.
- Lightsail "IPv6 only" bundles at $3.50/mo have no public IPv4 address.
- Lambda beyond the free tier (Mumbai): $0.0000002 per request (tier 1 price for requests), $0.0000166667 per GB-second (tier 1 x86).
- Azure Container Apps lists an "Environment Management Hour" at $0.14/h in Central India (Retail API). Whether it applies to the Consumption plan is UNKNOWN. If it does, it adds about 102.20 (d) per month.
- Azure Central India PostgreSQL storage: the Retail API returned no storage meter for Central India, so the storage price is UNKNOWN. Minimum storage is 32 GiB.
- Azure backup storage: free up to the provisioned storage size; beyond that $0.095/GB-mo (Central India, Retail API; the docs confirm the free-allowance rule).
- Azure Standard static IPv4: $0.006/h (Retail API; productName reads "Public IP Prefix", meter "Standard Static IP Addresses").
- Azure Static Web Apps Free plan is labelled "For personal projects"; production use is intended for the Standard plan (price not fetched).
- Azure free account ($200 credit for 30 days) is a trial and needs a card. It is not an always-free allowance.
- GCP Cloud Run regional tier: the fetched text lists asia-south1 (Mumbai) under "Subject to Tier 1 pricing". Verify before relying on it.
- GCP Cloud SQL pricing page is a region-selector page. The static text has no Mumbai shared-core price, and the Mumbai dedicated-core rates in the page data have no label for edition or machine type.
- Cloud SQL retained backups for deleted instances default to four days. A longer retention is an explicit setting.
