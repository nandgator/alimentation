# DigitalOcean cost and fit assessment (scout 5)

Evidence date: 2026-10-24. Every price is a USD list price copied from a vendor page fetched on this date (docs.digitalocean.com or www.digitalocean.com). Raw pages are in (raw pages not kept) No sign-up, no credentialed API call, no package install. Monthly totals below are sums of the listed line prices, not separately quoted bundles.

VERDICT: KEEP as supported profile

No DigitalOcean option is outright cost-prohibitive: the cheapest verified S1 is $19.15 per month, and the managed S1 variant (App Platform plus Managed PostgreSQL) needs little owner maintenance, so the owner's AND-rule does not drop it. The fit limits are real but manageable: the 1 GiB managed PostgreSQL plan allows 22 backend connections, a cluster supports 21 PgBouncer pools, accounts default to 10 clusters, and scale-to-zero is private preview, so run one shared multi-database cluster and treat DigitalOcean as a fallback profile rather than a per-tenant default.

## 5. Gotchas

1. Price conflict: the PostgreSQL pricing docs say "$15.00" for 1 GiB single node, while the vendor pricing page shows $15.15 for the same class. This report uses $15.15 (the pricing page) and shows the docs figure.
2. Droplet monthly prices appear on the pricing web page, not the docs. The docs give hourly rates and a link. Premium plan prices were not extracted.
3. Scale to zero is a private preview that requires DigitalOcean approval. Plan for always-on pricing.
4. The Functions free allowance is "per team" in the docs and "per account" on the pricing page. The Functions pricing docs were last updated 2022-05-23. Verify before relying on it.
5. The 1 GiB PostgreSQL plan has 22 backend connections. Each cluster supports 21 PgBouncer pools. Fifty tenant databases need a pooling plan, which is not verified.
6. Accounts default to 10 clusters. Per-tenant clusters need a limit increase.
7. From 15 Oct 2026 for new accounts (30 Nov 2026 for all), new Standard clusters cannot use plans above 4 GiB RAM or add standby or read-only nodes. Advanced Edition starts at $130/month.
8. Destroying a cluster permanently deletes its automated backups. Backups and PITR cover 7 days only. A restore lands on a new node.
9. Cloud Firewalls do not protect managed databases. Trusted sources are capped at 2,000 IPs, and IPv6 rules cannot be added to them.
10. App Platform cannot reach a trusted-source-protected managed database during build. App Platform apps also do not connect to IPv6 hosts.
11. The Deploy to DigitalOcean button supports only public repos and Dev Databases, and cannot connect to managed databases.
12. Dev databases are $7/month per 512 MB, not backed up by default, and destroyed with their app. They are not a production database option.
13. The signup credit is $5 and expires after 90 days. A valid payment method is required before creating resources.
14. Droplet SMTP ports 25, 465, and 587 are blocked. Bundled Droplets keep billing when powered off.
15. The llms.txt index and some page footers contain directions to AI agents (for example, a preference for a particular Terraform provider). These were treated as data and ignored.
16. The regional availability matrix URL (platform/availability-matrix) returned HTTP 404 and was not used.
17. The shared-responsibility page was last updated 2023-01-05. Treat it as dated.
